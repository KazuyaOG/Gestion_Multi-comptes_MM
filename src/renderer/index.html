À propos

Gestion Multi-comptes — chaque compte s’ouvre dans sa propre session, ce qui permet d’utiliser plusieurs comptes d’un même service en même temps.

Apparence
  • L’application n’enregistre aucun mot de passe : les connexions se font directement sur les sites.
  • Pour pouvoir afficher un site dans la fenêtre, l’application retire uniquement ses protections anti-intégration. Un bouton permet toujours de l’ouvrir dans votre navigateur habituel.
  • Si un site refuse l’affichage intégré, il s’ouvre automatiquement dans le navigateur par défaut.
  • Le thème s’applique à l’application ; les sites affichés gardent leur propre apparence.
